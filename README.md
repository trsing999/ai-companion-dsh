# AI Companion on DSH

**给一个 AI 有限的身体、有限的钱、有限的自由。**

这不是一个聊天机器人项目。

它把 `dsh-world`（一个会人格化的 agent 运行时）接上了一套外部能力：眼睛、手、房间、作息、边界和一个总开关。核心问题不是"怎么让 AI 更聪明"，而是：

> **怎么让一个 AI 在真实电脑上长期活着，而不变成噪音或者事故。**

---

## 它和普通 AI 助手有什么不同

| 普通助手 | 这个项目 |
|---|---|
| 你说一句它答一句 | 它有作息，会自己醒来做事 |
| 没有持久记忆 | 有房间，日记、自述、顾虑都落盘 |
| 只有对话 | 有身体：能截屏、能弹气泡、能读硬件 |
| 想干什么干什么 | **有些事要人批准**（例如切歌） |
| 没有边界 | **气泡有上限**，防止把屏幕糊住 |
| 关掉就没了 | 服务独立于宿主，宿主关了还在攒材料 |

## 四个核心设计决定

### 1. 人格住在文件里，不住在 prompt 里

自述、日记、顾虑都写成 markdown 放在房间目录。每次醒来读文件，而不是把一大段人设塞进 system prompt。

**理由**：prompt 里的东西会随会话消失，文件里的会留下。

### 2. 给事实，不给剧本

不写"分数低时要傲娇"。只把真实发生的事记下来：

```
- 2026-11-01 01:01  写了一封信
- 2026-11-03 20:48  被叫停了一次
```

让它自己决定今天是什么心情。

**理由**：给了打分规则，它就会开始为分数表演。

### 3. 花钱的地方收口

| 类型 | 成本 |
|---|---|
| 抓歌、抓新闻、抽帧、量硬件、拼梦 | **0**（纯本地） |
| 只有"理解/表达"才调模型 | 有，且可预算 |

### 4. 一个休克开关

`Ctrl+Alt+Esc` —— 一键停掉所有后台服务，不动宿主进程本身。

**理由**：给它自由的前提是能随时收回。

## 她能干什么

不是"能聊什么话题"，是**真的动手做**。下面每一条都有对应脚本。

### 🎬 视听

| 能力 | 脚本 |
|---|---|
| 听见你在放什么歌，还能查到歌词在唱什么 | `now_playing.py` |
| 想切歌？先问你，你点头才切（10 分钟有效） | `pet_music.py` |
| 你按 `Ctrl+Alt+S`，她看你一眼屏幕 | `screen_hotkey.py` |
| 也能 `Ctrl+Alt+L` 让她主动看一眼 | `hotkey_look.py` |
| 看屏幕还能离线 OCR 出文字（不调视觉模型） | `look_screen_ocr.py` |
| 认颜色，给每种颜色起中文名 | `eye_color.py` |

### 📚 学

| 能力 | 脚本 |
|---|---|
| 用你的登录态在 B 站搜课（**只读**，不点赞不评论） | `hnu_course.py` |
| 读你的关注 / 收藏 / 稍后再看 / 观看历史 | `bili_account.py` |
| 刷 B 站热门 | `bili_scout.py` |
| **自己下载整讲 → 抽帧 → 存进房间**，不用人播放 | `learn_video.py` |
| 把课程目录整理成能打勾的清单 | `gen_course_index.py` |
| 每天读一段《世说新语》（393 条） | `classic_daily.py` |

### 📺 看番

| 能力 | 脚本 |
|---|---|
| 你在看动漫时，悄悄截一集给她 | `auto_watch.py` |
| 定时截屏攒成图列，她自己一张张看 | `watch_anime.py` |

### 🌍 感知

| 能力 | 脚本 | 成本 |
|---|---|---|
| 天气 + 新闻，15 分钟刷一次 | `outside_world.py` | 0 |
| 电脑的 CPU / 内存 / 电量 | `breath.py` | 0 |
| 现在开着什么窗口 | `hotkey_look.py`、`peek.py` | 0 |

### 💬 说话（六条通道）

| 通道 | 脚本 | 特点 |
|---|---|---|
| 桌宠气泡 | `world_to_pet.py` | 你开什么窗口都看得见 |
| 手机推送 | `notify_mobile.py` | Server酱 / 企业微信机器人 |
| Windows 通知 | `win_toast.py` | 系统级，但可能被优化软件吞 |
| 网页聊天入口 | `chat_web.py` | 局域网，带防护 |
| 邮件双向 | `email_bridge.py` | 你发邮件给她，她用邮件回 |
| 全镜像到手机 | `world_mirror.py` | 她说的每句话 + 每篇日记 |

### 🌙 生活

| 能力 | 脚本 |
|---|---|
| 每晚 23:30 做一个梦（把白天碎片硬拼） | `dream.py` |
| 老实记录发生过的事（**不记分**） | `memory.py` |
| 画浮到桌面右下角，看完点一下收起来 | `art_on_desktop.py` |
| 夜里困了会犯困 | `pet_night.py` |

### 🔧 运维

| 能力 | 脚本 |
|---|---|
| `Ctrl+Alt+Esc` 一键叫停所有后台 | `kill_switch.py` |
| 环境自检：能跑哪些、缺什么 | `doctor.py` |
| 一键演示（0 token） | `demo.py` |
| 缓存清理（永不碰日记和画） | `cleanup.py` |
| 她的家索引页（每次重新扫描） | `her_home_index.py` |
| 状态报告：日记、房间、花费 | `pet_status.py` |

## 30 秒先看一眼

```bash
pip install -r requirements.txt
python tools/doctor.py     # 自检：这台机器能跑哪些，缺什么
python tools/demo.py       # 演示：零成本看它在干什么
```

`demo.py` 会当场演示三件事，**一次模型都不调、一个文件都不写**：

```
① 感知   读这台机器的 CPU / 内存 / 电量（纯 ctypes，不用 psutil）
② 做梦   把样例房间里的碎片硬拼成一段梦（纯字符串，0 token）
③ 限流   气泡有额度，连发三条会被拦（跨进程文件锁）
```

## ⚠️ 这不是开箱即用的产品

它是**参考实现**。克隆下来能立刻跑的是感知层和工具层，**完整系统需要宿主**：

| 想要 | 需要什么 |
|---|---|
| 量硬件、做梦、看限流、清缓存 | ✅ 克隆就能跑 |
| 自助看课、读经典、抓天气 | + `opencv-python`（看课还要 B 站登录态） |
| 发手机推送、收发邮件 | + 各自的配置文件（见 `config/examples/`） |
| **完整的人格 + 桥接 + 气泡** | **+ [`dsh-world`](https://github.com/) 宿主插件，它不在这个仓库里** |

没有宿主，你能看到全部代码逻辑，但不能让她"活着"。

## 隐私

**这个仓库里没有任何人的个人数据。**

- 没有真实用户名、家目录路径、邮箱
- 没有 API key / 登录凭证 / 推送密钥
- 没有房间内容、日记、聊天记录
- 所有配置样例都是假值（`SCT_FAKE_KEY` 之类）
- `logs/`、`downloads/`、`room/` 全部在 `.gitignore` 里

设计文档里提到的"她"指的是运行时的 agent 实例，不指任何具体的人。

## 已知的问题

诚实列出来：

- **强依赖宿主**：核心人格层是 `dsh-world` 插件，不能脱离它运行
- **Windows only**：大量用了 `ctypes` 调 Win32（`GetSystemPowerStatus`、`RegisterHotKey`、`EnumWindows`）
- **没有测试**：全靠运行日志和人工验证
- **部分路径硬编码**：见 `docs/SETUP.md` 的移植说明
